LED vs Botão — Por quê?

Botões (PWR SW, RESET)

Apenas um curto-circuito momentâneo entre dois pinos.
Não há fluxo contínuo — a corrente pode ir em qualquer direção.

LEDs (PWR LED, HDD LED)

São diodos: conduzem corrente em apenas uma direção.
Polaridade invertida → LED apagado. Sem risco de queima.

Speaker — A Voz do Sistema

O que é?

Pequeno alto-falante interno que emite sinais durante o POST.

Importante

Sem speaker →\rightarrow diagnóstico sonoro não existe.

Função

Indicar falhas mesmo sem vídeo na tela.

Beep Codes — Exemplos

  • 1 beep curto →\rightarrow sistema OK

  • Beep contínuo / 3 beeps →\rightarrow problema na RAM

  • 1 longo + 2 curtos →\rightarrow problema na GPU

Placas modernas

Substituem beeps por LEDs de diagnóstico:
CPU — DRAM — VGA — BOOT

USB Frontal — Conexão

Procedimento

  1. Localizar header USB na placa

  2. Identificar o tipo (2.0 ou 3.0)

  3. Alinhar pelo pino bloqueado (chave)

  4. Encaixar sem forçar

USB Frontal — Estrutura do Sinal

Como funciona?

USB transmite dados e energia pelo mesmo cabo:

  • +5V (alimentação do dispositivo)

  • GND (terra de referência)

  • Linhas de dados D+ e D−-

Analogia

Como uma API: energia = servidor ligado
dados = requisições trafegando

Áudio Frontal — Visão Geral

Função

Conectar fone de ouvido e microfone do gabinete.

Padrões

  • HD Audio — moderno, qualidade superior

  • AC’97 — legado, compatível por software

Importante

Sempre prefira HD Audio.
AC’97 pode causar ruído ou falhas.

Boot

Boot Passo a Passo

  1. Botão pressionado

  2. PWR SW fecha o circuito

  3. Placa-mãe envia PS-ON à fonte

  4. Tensões ATX sobem (+12V, +5V, +3,3V)

  5. CPU recebe energia e inicia

  6. CPU busca BIOS na memória flash

  7. BIOS executa o POST

  8. Sinal de vídeo disponível na tela

  9. BIOS varre dispositivos de boot

  10. Sem HD →\rightarrow “No Boot Device” (esperado hoje)
